# 14.3 Professional Relationship Mode

**Area:** 14. Collaboration Modes

A mode optimized for work relationships.

## Capabilities

- Track stakeholder preferences.
- Track meeting follow-ups.
- Track client milestones.
- Prepare for performance reviews.
- Draft professional messages.
- Remember communication preferences.

## Implementation Notes

This may become a separate product tier.

## Current workflow

Choose **Professional** in the existing relationship profile form, then record organization, stakeholder role, communication preferences, work goals, boundaries and performance-review preparation. Classification is explicit and independent of colleague, client, mentor, vendor or custom relationship type; existing profiles remain Personal.

Meeting notes use the existing public profile notes editor (public here means eligible profile context, not shared with other people). Commitments track follow-ups, important dates track client milestones, preferences retain stakeholder preferences, and gift history retains work gestures. Save those records, then select up to six per category in work context. Selected references stay live; private or vault-protected notes cannot enter professional context. The selector shows the latest 100 records and existing selections. The professional overview links to notes, commitments, milestones and briefings for meeting or performance-review preparation. Cadence and private reminders remain the core follow-through tools.

Professional drafts use professional tone; briefings, gift recommendations and event suggestions consume only selected work sources and dedicated encrypted work context. Personal and vault context are excluded even if generation flags are submitted. Gifts require an explicit suitability confirmation and recorded work boundaries; gift-box companion suggestions are withheld in professional mode. Saved generated material remains separated by mode in the profile workspace. Professional context is included in owner exports and removed with the profile. No message, purchase, contact or sharing occurs automatically.

Switching back to Personal retains the encrypted work settings but excludes them from personal generation. Owners can edit or clear the settings at any time. The profile's original manual records remain owner-readable; classification does not relabel or share them.
